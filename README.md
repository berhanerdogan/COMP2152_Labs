## Weekly Overview

### Week 01 — Variables & Basics
Practice with variable declaration, arithmetic operators (exponentiation, modulo, integer division), and f-string formatting. A simple input/output program reads the user's age and performs a calculation.

### Week 02 — Conditionals & Randomness
A Rock-Paper-Scissors game built using the `random` module. User input is validated with a `while` loop, and the winner is determined through `if/elif/else` blocks.

### Week 03 — Data Structures (6 Questions)
An in-depth look at Python's core collection types: list operations (student grades, shopping cart), tuple unpacking with Euclidean distance, set operations (class attendance, intersection/union/difference), dictionary CRUD (contact book), and a combined inventory system using all four types.

### Week 04 — Loops & Functions
Four LeetCode-style problems: checking whether a robot returns to its origin, solving Two Sum with both a brute-force nested loop and an optimized O(n) dictionary approach, array shuffling, and finding the first unique character in a string.

### Week 05 — Recursion
Recursive Fibonacci sequence, FizzBuzz list generation, and Binary Search implemented in both iterative and recursive forms, with results verified side by side.

### Week 06 — File I/O & Network Diagnostics
System commands (`ping`, `nslookup`, `ifconfig`, `arp`) are run via `subprocess`, and results are logged to both `.txt` (append mode) and `.csv` files. Exception handling with `try/except/finally` is added to build a complete interactive Network Diagnostic Logger.

### Week 07 — Midterm Week
No lab.

### Week 08 — Intersession Week
No lab.

### Week 09 — System Info, Threading & Unit Testing
Three problems: reporting system information using the `platform` module, comparing sequential vs. parallel task execution with `threading`, and writing automated tests with `unittest` for a Celsius-to-Fahrenheit converter and an IPv4 address validator.

### Week 10 — SQLite Databases
Three database-backed applications using `sqlite3`: a password vault with full CRUD, a login attempt tracker recording success/failure events, and a security audit log. The final question includes `unittest` tests for database queries.

### Week 11 — Introduction to OOP

Three classes built around familiar cybersecurity concepts. A `PortScanner` class wraps the Assignment 2 socket logic into an object that holds its own target and results. A `PasswordChecker` class evaluates passwords against a common-password list and three strength criteria (length, digit, special character), rating them as WEAK, MEDIUM, or STRONG. A `Finding` and `Report` class pair represents vulnerability reports, with filtering by severity and a formatted summary output.
